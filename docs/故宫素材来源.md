## 景点一句介绍与官方依据

以下为对官方资料的简短改写，便于用于卡片与讲解内容。

| 景点 | 一句介绍 | 官方依据 |
| --- | --- | --- |
| 午门 | 午门是紫禁城南端的正门，凹字形城台与五座门楼构成了层次分明的宫城入口。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236454.html) |
| 太和门 | 太和门是紫禁城外朝的正门，门前内金水河上的五座石桥与两侧廊庑共同组织入口广场。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236439.html) |
| 太和殿 | 太和殿是外朝三大殿之首，明清皇帝在这里举行登极、大婚等重要典礼。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236465.html) |
| 中和殿 | 中和殿位于太和殿与保和殿之间，采用单檐四角攒尖顶，皇帝参加大典前曾在此休息和接受执事官员朝拜。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236464.html) |
| 保和殿 | 保和殿位于外朝三大殿的北端，清代既用于宫廷宴会，也曾用作殿试场所。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236434.html) |
| 乾清宫 | 乾清宫是内廷后三宫的首座正宫，明代与清初曾为皇帝寝宫，清雍正以后仍承担理政和典礼等功能。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236472.html) |
| 交泰殿 | 交泰殿位于乾清宫与坤宁宫之间，清代曾存放二十五方宝玺，也是皇后生日接受庆贺的地方。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236467.html) |
| 坤宁宫 | 坤宁宫在明代曾为皇后寝宫，清代改建后主要用于萨满祭祀，并保留皇帝大婚的相关空间。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236487.html) |
| 御花园 | 御花园位于坤宁宫北侧，以钦安殿为中心，亭阁、古树、山石与彩石甬路构成宫城中的园林空间。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236519.html) |
| 神武门 | 神武门是紫禁城的北门，明代称玄武门，清代因避康熙帝名讳改为现名。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236456.html) |
| 宁寿宫区 | 宁寿宫区位于内廷外东路，其中皇极殿是乾隆为归政后临朝受贺而改建的主体建筑。 | [故宫博物院](https://www.dpm.org.cn/show/225714.html) |
| 慈宁宫区 | 慈宁宫位于内廷外西路，清代曾为太皇太后和皇太后的正宫，也承担祝寿等重大庆贺典礼。 | [故宫博物院](https://www.dpm.org.cn/explore/building/236504.html) |
