# 景见

把景点照片与资料，整理成游客可以浏览、探索的景区预览。名称暂定，当前为黑客松原型。

景区人员在维护端管理地图、景点和多视角素材；游客从地图选择景点，查看实景照片，并进入已接入的三维空间。当前试点为**西湖花港观鱼·御碑亭**。

**[在线体验](https://jingjian-studio-redesign.raremint.chatgpt.site/#map)** · **[御碑亭三维试点](https://jingjian-studio-redesign.raremint.chatgpt.site/#pilot)** · **[景区维护端](https://jingjian-studio-redesign.raremint.chatgpt.site/#studio)** · **[文档目录](docs/README.md)**

## 当前能体验什么

截至 2026-10-12，公开站点已发布第 4 版。

| 能力 | 当前实现 |
| --- | --- |
| 游客地图 | 一张 AI 插画地图，六处真实景点，点位可点击进入详情；地图不是地理导航 |
| 实景照片 | 御碑亭、断桥、平湖秋月、曲院风荷、三潭印月、雷峰塔，附来源与许可 |
| 照片 | 六个审核视角（正面、两侧、背面、俯视、近景），外加不限数量的补充照片；上传、查看、接受或移除 |
| AI 补图 | 内置 imagegen 预生成的五张御碑亭补图；网页按钮返回固定样例，未接实时补图 API |
| 真实世界模型 | 御碑亭内置 Marble 1.1 生成的 SPZ，可环顾、移动、升降和重置 |
| 实时 3D 生成 | 维护端 3D 标签把正面、两侧、背面照片（含已接受的 AI 补图）送入 World Labs Marble；可选快速草稿（约 230–250 credits）或精细版（约 1,580–1,600 credits），显示上传、生成、下载进度，完成后直接预览并可发布。需本机服务与 `WORLDLABS_API_KEY` |
| 3D 漫游范围 | 维护端 3D 标签逐方向调整，预览即时生效，随发布到游客端 |
| 发布预览 | 草稿与游客快照独立；发布只影响当前浏览器，不是上传到云端 |
| AI 导游 | 本机配置 `ANTHROPIC_API_KEY` 时，用 Claude（Anthropic Messages API）只依据维护端讲解资料与运营提示作答；未配置或请求失败时退回逐句检索。资料外问题如实说明。内置六处讲解为演示整理，需景区核实 |

御碑亭模型的实际输入是**一张正面实拍**。五张 AI 补图没有送入这次世界生成。模型的未见区域是推测，不能保证完整、精确或实际可通行；其余五个景点当前提供照片预览。

## 本地启动

准备 Node.js（本机验证 24.x）。依赖版本在 package.json 中固定。

```sh
git clone https://github.com/Arlencl/hackathon-2026.git
cd hackathon-2026
npm install        # 首次；也可用 pnpm install
npm start          # 构建 → 启动服务 → 自动打开浏览器
```

改代码时用 `npm run dev`：保存 `src` 下的文件后自动重新构建，刷新浏览器即可。按 Ctrl+C 停止。

打开 [本地景区地图](http://127.0.0.1:4173/#map) 或 [本地三维试点](http://127.0.0.1:4173/#pilot)。观看仓库自带的场景不需要模型密钥，也不会再次生成或扣费。

`dist/` 不提交到 Git，由启动命令生成。macOS 也可双击 [启动景见.command](启动景见.command)，效果同 `npm start`。完整配置和故障处理见 [开发与部署](docs/开发与部署.md)。

## 页面入口

| 路径 | 用途 |
| --- | --- |
| `/`、`/#home` | 产品官网：介绍工作流，分别进入游客端和景区维护端 |
| `/#scenics` | 游客首页：所有已发布景区的卡片列表 |
| `/#map?s=westlake` | 某个景区的地图，点击点位就地预览 |
| `/#spot?s=westlake&id=huagang` | 景点照片详情与 3D 漫游入口 |
| `/#pilot?s=westlake&id=huagang` | 御碑亭全屏 3D 漫游（实拍驱动的真实三维试点） |
| `/#studio` | 维护端首页：我的景区，新建或删除景区 |
| `/#studio?s=westlake` | 编辑单个景区：景点列表 + 基本信息 / 照片 / 导游 / 3D 标签，顶栏发布 |

不带 `s=` 的旧链接默认指向西湖；其他路径回到产品官网。

## 验证与当前边界

```sh
npm test
npm run build
```

`npm test` 运行全部单元测试；浏览器流程在本机 headless Chrome 中检查过。此记录不代表每台设备的性能保证。

上传地图、照片和新维护端发布内容保存在浏览器 IndexedDB。其他人访问公开链接会看到内置演示，不会收到你的本机草稿。图片按内容存为独立 Blob，草稿与发布共用，数量只受浏览器存储配额限制。维护端可导出含图片的备份，目前没有恢复界面。

尚未完成景区账号、云端素材发布、多人协作、实时补图 API 和现场精度验收。实时 3D 生成与大模型导游只在本机 `npm start` 下可用：密钥只留在本机服务，生成的场景保存在 `data/worlds/`。公开站点是纯静态构建，只能看内置演示，导游退回资料检索。
