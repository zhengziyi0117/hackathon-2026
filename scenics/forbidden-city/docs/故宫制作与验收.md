# 故宫 · 宫阙之间：制作与验收

2026-10-14；景区 ID `forbidden-city`。本次在原有西湖引擎上实现第二个景区，保留现有游客 UI 和工作室，不另做一套页面。

## 交付内容

- 12 个景点：午门、太和门、太和殿、中和殿、保和殿、乾清宫、交泰殿、坤宁宫、御花园、神武门、宁寿宫区、慈宁宫区。
- 皇家微缩、积木宫城两种风格，共享宫墙、护城河、殿堂、停靠点和通行规则；晴日、夕照、瑞雪分别由光照、天空、材质与粒子变化呈现。
- 10 站中轴导览，可开始、继续和退出；午门、太和殿、乾清宫、御花园四枚印章。选中景点时先前往殿前观赏点，再看实景、听讲解或向导游提问。
- 增加故宫内容种子并兼容旧工作区。保留已有草稿、发布快照、上传素材与删除决定；按景区隔离游览位置、风格和印章。
- 12 张本地实拍图、可追溯讲解资料、ImageGen 绘卷。故宫当前提供沙盘与照片游览，没有冒用西湖世界模型；局部实景世界需另选可对齐视角并审核后生成。

## 四层文件与渲染扩展

地图包位于 `scenics/forbidden-city/map/`。四层采用 `schemaVersion: 2`，西湖仍为 v1；风格版本不变。1 地图单位对应约 20 米，仅用来表达布局与路线估算，整份数据是人工整理的游览示意，不是测绘成果。

- `geography.json`：宫城水域、主殿相对位置、建筑实体、门洞、332 个路网节点与 1,374 条候选边。实体与门洞限制所有移动方式，寻路编译时剔除不允许的方向。
- `layout.json`：184 个受控模型实例、植被范围、庭院铺装、组件开关。模型引用地理实体，校验位置与宽深一致，避免渲染和碰撞使用两份坐标。
- `interaction.json`：中轴顺序、四枚印章、12 个停靠点、单向入口/出口、关闭提示、相机与角色尺度。
- `styles/imperial*.json`：独立材质、造型、灯光和三种氛围。切换风格保留当前人物位置、路线、印章与氛围。

`architecture.js` 提供殿堂、城门、宫墙、台基、角楼和铺装组件。背景配院按材质合批；可点击地标保持独立对象。`scene.js` 通过地理实体读取庭院与花木范围，没有写入故宫坐标。

## 视觉修订

初版的问题是屋面高频细瓦线、重复细部阴影，以及大面积单色地面。本次调整：

1. 去掉每条瓦楞的细管几何，保留曲面、宽屋脊、翘檐与重檐轮廓。瓦面采用导数过滤，远景细节淡出；测试检查屋顶面方向与有限顶点，避免阴影和积雪表现异常。
2. 对纵向侧廊采用纵向屋脊，降低栏杆重复密度，把青绿彩绘梁与斗拱放回屋檐下方。
3. 院落使用青灰石缝、浅色轴线、局部铺装分区；配院补齐围合，园林区加入古柏、树冠、围石与石景。主要礼仪广场保持开阔。配院和植物位置为展示性简化。
4. 强化朱墙、金瓦、白石与青绿的层次，调整日照、雾距、沙盘厚度和总览视角，降低水面高光和岸线白沫。
5. 在后期渲染目标上启用 4x MSAA，避免只对主画布抗锯齿却漏掉后期链；关闭三维地图浮层的背景模糊，解决 WebKit 与移动 WebGL 叠加时的方块伪影。

## 来源与使用范围

照片作者、许可、来源页、原图、修改说明和 SHA-256 保存在 [sources.json](../provenance/photo-sources.json)，人工筛选记录见[故宫素材来源](故宫素材来源.md)。照片为不同年份、不同范围的记录，宁寿宫区照片展示皇极殿，慈宁宫区照片是正殿局部。

绘卷产物为 [palace-scroll.jpg](../assets/palace-scroll.jpg)，完整输入见[生成提示词](故宫绘卷生成提示词.txt)。它作为艺术绘卷使用，不能提供准确建筑数量、门洞与通行依据。2D 图钉单独校对；3D 几何不从插画像素反推经纬度。

太和门依据设计阶段检索的[官方施工公告](https://www.dpm.org.cn/announce_detail/379422.html)保留建筑、关闭主通道，以侧向绕行表达游览顺序。地图里的具体绕行仍是示意，实际开放须按故宫当日公告与现场标识复核。

## 验证方式与边界

```sh
node scripts/validate-map.mjs scenics/forbidden-city/map/manifest.json
npm test
npm run build
```

默认校验和构建检查全部地图包，报告分别保存为 `artifacts/map-validation-forbidden-city.json` 与 `artifacts/map-validation-westlake.json`。报告包含输入文件哈希。

新增测试覆盖：入口到 12 处停靠点、各点到出口、10 站导览顺序、阻挡/单向门/关闭通道/桥、两风格模型边界与法线、旧数据迁移与删除保留、照片许可和文件哈希。西湖地形与路网基线测试继续保留。

台基、建筑实体不能穿越，游客停在殿前；小部件、花木和栏杆没有逐件物理碰撞。台阶用于外观，当前不做进入殿内或登上台基的游览。没有声称此沙盘精确对应现场可开放空间，也没有将动画步速换算为实地导航速度。

具体设备性能尚未建立基准，不能据此承诺所有设备 60 fps。单景点世界、云端协作、实时补图 API 与景区现场精度审核沿用项目原有边界。
