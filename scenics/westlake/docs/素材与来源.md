## 网页副本与再分发

各景点的 `web/` 目录保存由原素材制作的 JPEG 网页副本。处理包含缩放与压缩，没有重新生成景物；缩略图还可能被 CSS 裁切。具体原文件、副本、字节数和哈希见 各级 `assets.json`（例如[御碑亭清单](../spots/huagang/assets.json)）。

原图与网页副本共享相应来源许可，不因文件变小而改变素材身份。再分发或改作时保留作者、来源、许可与变化说明；项目中的素材具有不同许可证，不应把整仓素材笼统描述为无条件商用或统一 MIT。
